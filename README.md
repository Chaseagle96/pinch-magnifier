# Pinch-to-Zoom

**Natural, gesture-based screen magnification for GNOME.**

Pinch-to-Zoom brings intuitive, multi-touch gesture magnification to the GNOME desktop. Zoom in and out of your screen using familiar trackpad pinch gestures, making desktop navigation more accessible, comfortable, and effortless.

Designed with accessibility, simplicity, and a seamless desktop experience in mind.

---

## Overview

Magnifying your desktop shouldn't interrupt the way you work.

Pinch-to-Zoom provides a natural way to interact with desktop magnification using multi-touch trackpad gestures. Instead of relying exclusively on keyboard shortcuts or navigating through system settings, users can simply pinch to zoom.

The goal is straightforward: make screen magnification feel like an intuitive extension of the desktop itself.

## Features

- **Natural pinch gestures** – Zoom in and out using familiar multi-touch trackpad gestures.
- **Accessibility-focused** – Makes desktop content easier to see through convenient, gesture-based magnification.
- **Intuitive interaction** – Uses gestures that trackpad users already understand.
- **Seamless desktop experience** – Designed to integrate naturally into the GNOME desktop environment.
- **Simple by design** – Focuses on making magnification accessible without unnecessary complexity.

## Why Pinch-to-Zoom?

Desktop accessibility tools are essential, but interacting with them should be straightforward.

Traditional magnification workflows can require keyboard shortcuts, additional configuration, or navigating system menus. Pinch-to-Zoom aims to make that interaction more natural.

Inspired by the familiar pinch-to-zoom experience found on smartphones, tablets, and other touch-enabled devices, this extension brings that same interaction paradigm to the Linux desktop.

**Accessibility should feel effortless, not like an additional task.**

## Troubleshooting

If the extension does not behave as expected:

1. Verify that your trackpad supports multi-touch gestures.
2. Confirm that the extension is enabled.
3. Verify that your GNOME Shell version is supported.
4. Check the project's GitHub Issues for known problems.

If you encounter a bug, please consider opening an issue with:
- Your Linux distribution.
- GNOME Shell version.
- Trackpad model.
- Steps to reproduce the issue.
- Relevant error messages or logs.
